# ScoreTrack 4 - 4人制ゲーム戦績管理Webアプリ

麻雀や各種ボードゲームなどの4人制ゲームを対象とした、複数卓・同日開催セッション対応の戦績・スコア管理Webアプリケーションです。  
スマートフォン（iPhone/Android）およびPCでの快適な操作に最適化されており、GitHub Pagesへプッシュするだけで即座に利用可能です。

---

## 主な機能

### 1. セッション管理（日付 × 場所 / 卓）
- 同日に複数卓（例: 「新宿A卓」「新宿B卓」）や異なる場所で開催されるケースに対応
- 日付と場所・卓名でセッションを作成・切り替え・再編集可能
- 過去の場所名のクイックサジェスト機能

### 2. リアルタイム対局入力 & 合計0判定
- **常時固定Sticky Header**: スクロールしても画面上部に4名の合計スコアと平均順位をリアルタイム表示
- **合計0バリデーション**: スコア入力中、4名の合計がジャスト「0」かどうかをリアルタイム判定。不一致時は赤字警告と必要差分を表示
- **自動順位計算 & 手動上書き**: スコアの高い順に1位〜4位を自動判定。ドロップダウンから手動で1〜4位の上書きも可能
- **テンキー入力・符号トグル**: `inputmode="decimal"` 対応およびワンタップで正負を反転する「±」ボタンを装備

### 3. 通算戦績・統計（Stats）
- 場所/卓フィルター（全期間 / 特定の卓で絞り込み）
- 集計項目:
  - プレイヤー名、総対局数
  - 1位 / 2位 / 3位 / 4位の回数および順位率（%）
  - 連対率（1位+2位率 %）
  - 平均順位（小数第2位）
  - 通算累計スコア
  - 平均スコア（スコア / 対局）
- 各カラムのクリックによる昇順 / 降順ソート対応

### 4. プレイヤー管理
- プレイヤーの新規登録、名前変更、削除
- 席順（東・南・西・北）へのプレイヤー割り当て

### 5. データバックアップ & Supabase連携対応
- **localStorage**: ブラウザ内にデータを自動保存
- **JSONバックアップ**: ワンクリックでJSONファイル保存およびクリップボードコピー
- **JSONインポート**: ファイルまたはテキスト貼り付けによる復元
- **Supabase移行設計**: `players`, `sessions`, `matches` のリレーショナル構造で設計されており、将来のクラウドDB（Supabase / PostgreSQL）への移行がスムーズに行えます

## GitHub Pagesへのデプロイ方法

1. このリポジトリをGitHubにプッシュします。
2. GitHubリポジトリの **Settings** > **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選択します。
4. Branch に `main`（または `master`）の `/ (root)` を指定して **Save** をクリックします。
5. 数分後に発行されるURL（`https://<username>.github.io/<repository-name>/`）にアクセスすれば、どの端末からでも利用できます。

## 開発・ローカル実行

ビルドツール不要のピュアHTML/CSS/JavaScriptで構成されています。
ローカルで確認する場合は、任意のHTTPサーバー（例: Python）で起動できます。

```bash
python -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。
